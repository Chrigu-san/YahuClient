# 🟩 Yahu Client
Unser eigener Minecraft Launcher. Basiert auf Prism Launcher, hat also alles was Prism kann, aber mit eigenem Design und eigenen Features.

**Aktuelle Version:** `0.1.7` (10. November 2026)
**Download:** [YahuClient-Setup.exe](https://github.com/Chrigu-san/YahuClient/releases/latest/download/YahuClient-Setup.exe)
-# Windows 10/11, 64 Bit. Falls Windows "Der Computer wurde durch Windows geschützt" anzeigt: **Weitere Informationen** und dann **Trotzdem ausführen**.

## ✨ Features
**Spielen**
- Mehrere Instanzen, jede Version und jedes Modpack in einem eigenen Ordner
- Fabric, Forge, NeoForge und Quilt
- Mods direkt im Launcher suchen und installieren (Modrinth)
- Java wird bei Bedarf automatisch heruntergeladen
- Anmeldung mit dem Microsoft Account
- "Zuletzt gespielt" als "vor 2 Tagen 5 Stunden"

**Server hosten**
- Eigenen Server mit ein paar Klicks erstellen: Paper, Vanilla oder Fabric
- Version, RAM, Spieleranzahl, Whitelist, PvP, Schwierigkeit und vieles mehr einstellbar
- Konsole direkt im Launcher, man sieht wer online ist
- **Kein Port Forwarding nötig:** Yahu Client öffnet den Port automatisch auf dem Router (UPnP)
- **Eigene Adresse:** Dein Server bekommt eine Adresse wie `chris.yahuclient.net`, die immer gleich bleibt. Deine Freunde müssen keine IP und keinen Port eintippen
- Mit der eigenen Adresse auch selbst auf den eigenen Server joinen

**Im Spiel** (Fabric 26.3)
- Dunkles, modernes Design für alle Menüs, Yahu Menü mit **Rechts Shift** und unseren Mods
- **Crosshair:** pixelgenau, Punkt, Kreis, Arme frei kombinierbar, für PvP
- **Lyrics:** Karaoke am Himmel, Zeile, Wort für Wort oder Kinetic
- **Skybox:** Schwarzes Loch, echter Tag, Polarlicht und eigene Bilder

**Design**
- Alles in einem Fenster, Dialoge öffnen sich als Overlay
- Block Design: Pixel Ecken, Knöpfe mit 3D Kante, viele Farben. Themes: Overworld, Black, Night Grass und Ocean
- Banner mit Sonnenuntergang, Wolken und Gras Hügeln
